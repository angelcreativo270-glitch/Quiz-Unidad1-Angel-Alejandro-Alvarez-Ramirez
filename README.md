### ¿Qué hice?
Modifiqué el archivo de reflexión agregando contenido adicional y registré un segundo commit.

### ¿Cómo lo resolví?
Añadí texto a `documentos/reflexion.txt` usando el operador de anexado `>>`, revisé los cambios con `git diff`, preparé el archivo y registré el commit.

### Herramientas o instrucciones utilizadas
- `cat <<EOT >> documentos/reflexion.txt`
- `git diff`
- `git add documentos/reflexion.txt`
- `git commit -m "actualiza reflexion con lo aprendido en el quiz"`
- `git log --oneline`

##Dificultades encontradas

Ingresar saltos de línea y múltiples párrafos de texto en archivos directamente desde la línea de comandos sin abrir un editor de texto gráfico como VS Code.

##¿Cómo solucioné esas dificultades?

Utilicé el comando `cat <<EOT > archivo.txt` (Heredoc) para escribir bloques completos de texto multilínea de forma limpia directamente desde Bash.

##Aprendizaje

Comprendí cómo llevar un control de versiones estricto apoyándome al 100% en la línea de comandos, lo que brinda mayor agilidad y comprensión profunda de las operaciones internas de Git.
